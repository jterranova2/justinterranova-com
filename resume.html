Summary

I started in operations, on warehouse floors and fleet yards, and kept building my own tools because the reports I needed didn't exist. That habit became my specialty. I design the data model, build the reporting people actually use, and automate the manual work in between. Now I add an AI layer on top, so a manager can ask the data a question and get an answer they can act on.

I've done this in five industries, and the pattern is always the same: the data is messy, the weekly report is built by hand, and nobody trusts the numbers. I fix that, then make it smarter.
